ПОДХОД

Новый дизайн оказался менее удобным. TuneRift возвращает знакомую структуру и не добавляет шум ради функций.

[ 01 / ВОЗВРАЩЁННЫЙ ИНТЕРФЕЙС ]

Такой дизайн
помнится сразу.

Знакомая навигация, «Моя волна», история и нижний плеер снова собраны в одном спокойном рабочем пространстве.

[ 02 / ПОЛНЫЙ ЭКРАН ]

Музыка —
на весь экран.

Готовый полноэкранный режим собирает крупную обложку, строки текущего трека и управление в более сосредоточенный интерфейс.

[ 03 / ФУНКЦИИ ]

Полезное —
в первую очередь.

01

Старый дизайн

Знакомая структура ПК-клиента возвращается для тех, кому она была удобнее нового интерфейса.

● УЖЕ ЕСТЬ
02

Discord Rich Presence

Discord показывает трек, исполнителя, обложку и состояние воспроизведения.

● УЖЕ ЕСТЬ
04

FckCensor

Встроенный аддон подбирает альтернативную версию трека, чтобы вернуть исходное звучание.

● ВКЛЮЧЁН ПО УМОЛЧАНИЮ
05

Удобное окно

Окно запоминает размер и позицию, добавляет настройки, область перетаскивания и чистит лишние блоки сервиса.

● УЖЕ ЕСТЬ
06

Настройки модов

Отдельное окно для управления Discord RPC, аддонами и локально сохранёнными настройками.

● УЖЕ ЕСТЬ
07

Полноэкранный режим

Отдельный интерфейс с крупной обложкой, текстом текущего трека и управлением без лишних элементов.
