# TuneRift — технические заметки об изменениях

## Apple Music Lyrics — последующие исправления 2026-11-18

Аддон снова управляется обычным переключателем: `forceDisabled` снят с манифеста, startup migration и IPC gate удалены. Код аддона и зависимость PulseSync shim сохранены. В account menu возвращена строка «Apple Music Lyrics»; включение и выключение применяются с перезагрузкой страницы.

Скриншот DevTools показал псевдоэлементы `::before` и `::after` у контейнера `[data-test-id="SYNC_LYRICS_CONTENT"]` внутри fullscreen-плеера. Они отключены только на этом узле через `content: none` и `display: none`. Также удалены масштабирование lyric-строк через inline `transform` и CSS-переопределение `position: relative` для всех дочерних элементов модального окна.

Для устранения оставшегося эффекта «размытие на старой строке» обновлён observer lyrics: он реагирует на изменение inline `style` у `.swiper-wrapper`, но игнорирует собственные style-изменения lyric-строк. Текущая строка выбирается по ближайшему к центру viewport положению; активный CSS-класс используется как резервный вариант.

## Discord RPC и macOS media controls

`src/discordRPC.js`, зависимость `discord-rpc` и основной RPC pipeline сверены с upstream GitHub. Preload использует исходную логику состояния: сначала актуальный Ynison, затем MediaSession. Позиция и длительность поступают от Ynison для таймлайна Discord. Глобальный перехват media keys и самодельная повторная регистрация MediaSession handlers удалены, чтобы Play/Pause обрабатывался штатным плеером Яндекс Музыки.

## FckCensor

Локальная адаптация сохранена, код из upstream FckCensor не переносился. Скрипт устойчивее к изменению webpack/DI имён и перехватывает текущий `GetFileInfoResource.getFileInfo`, чтобы подставлять URL замены в `downloadInfo`. Пакетная обработка DOM-событий снижает повторное сканирование ленты.

## Проверки

Проверены синтаксис изменённых JavaScript-файлов и валидность JSON-манифеста. Проверяется состояние dependency resolver при включённом/выключенном аддоне. CSS selectors и logic выбора активной строки проверены статически. Реальный fullscreen/player layout на macOS требует запуска приложения на устройстве.
