# TuneRift Mod

> Брендированный Electron-мод для **Яндекс Музыки** с Discord Rich Presence, классическим дизайном, визуальными улучшениями интерфейса и поддержкой аддонов.

TuneRift Mod запускает веб-версию Яндекс Музыки в отдельном Electron-приложении и добавляет функции, которых нет в стандартном клиенте. При этом интерфейс сохраняет привычный классический стиль Яндекс Музыки, а включение дополнительных возможностей управляется через собственное меню настроек.

Проект не связан с Яндексом, Discord или PulseSync. **TuneRift Mod является неофициальной пользовательской модификацией.**

## Возможности

### Discord Rich Presence

TuneRift Mod передаёт в Discord информацию о текущем воспроизведении:

- название трека;
- исполнителя;
- обложку композиции;
- состояние воспроизведения — play или pause;
- длительность и текущую позицию трека;
- движущуюся временную шкалу Discord Rich Presence;
- фирменное название активности **«Слушает TuneRift Mod»**;
- отображение названия приложения **«Слушает Яндекс Музыку»** в дополнительной информации.

Timeline синхронизируется с данными Ynison и обновляется при запуске, паузе, продолжении и смене трека. Состояние Discord RPC можно отключить в меню настроек приложения.

Для Discord Rich Presence используется собственное приложение Discord Developer. Client ID можно указать в конфигурации проекта или передать через переменную окружения:

```bash
DISCORD_CLIENT_ID=ваш_client_id npm start
```

Если Client ID уже задан в `src/discordRPC.js`, дополнительная переменная окружения не требуется.

### Классический дизайн Яндекс Музыки

В проект встроено расширение `extensions/old-design-builtin`, которое применяет классический дизайн на ранней стадии загрузки страницы. Благодаря этому старый интерфейс используется стабильнее, чем при поздней инъекции обычным аддоном.

Также в `extensions/` находится расширение `skip-webauthn-wait`, уменьшающее задержки, связанные с ожиданием WebAuthn в Electron.

### Собственное меню настроек

В профильное меню Яндекс Музыки добавляется пункт **TuneRift Mod**. Через него можно управлять функциями мода без редактирования исходного кода.

Настройки сохраняются локально с помощью `electron-store` и переживают перезапуск приложения. Доступные переключатели зависят от установленных аддонов, но основной набор включает:

- Discord Rich Presence;
- маркировку контента символом `E`;
- визуальные улучшения текста песен;
- UI-правки Electron-версии;
- загрузку пользовательских аддонов.

### Размытие текста песен в стиле Apple Music

Аддон `tweaked-ym-design` добавляет прогрессивное размытие строк синхронизированного текста. Дальние строки становятся менее заметными, а текущая строка остаётся читаемой. Эффект рассчитан на полноэкранный режим текста и не должен менять базовую центровку текста Яндекс Музыки.

В аддоне предусмотрены параметры визуального эффекта: максимальная сила размытия, прирост размытия на строку, прозрачность дальних строк и длительность перехода.

### Маркировка контента символом E

Аддон `explicit-e-mark` заменяет стандартный восклицательный знак Яндекс Музыки на знакомую пользователям Spotify маркировку `E` для треков с возрастными ограничениями и контентом 18+.

Маркировка добавляется без удаления исходной информации об ограничении и рассчитана на корректное отображение в старом дизайне Яндекс Музыки.

### UI-улучшения Electron-версии

Аддон `ui-tweaks` содержит визуальные и интерфейсные исправления, необходимые для запуска Яндекс Музыки в отдельном Electron-окне:

- адаптация элементов интерфейса под окно приложения;
- корректная область перетаскивания окна;
- обработка элементов, связанных с macOS-загрузкой;
- скрытие отдельных веб-блоков, которые не нужны в приложении;
- интеграция кнопки TuneRift Mod в меню аккаунта;
- поддержка пользовательских CSS-правок.

### Работа с PulseSync-совместимыми аддонами

Проект поддерживает собственный формат аддонов, вдохновлённый PulseSync. Аддоны могут содержать JavaScript и CSS, которые внедряются непосредственно в контекст страницы Яндекс Музыки.

В проект также включён экспериментальный `pulsesync-shim`. Он добавляет минимальный совместимый API для отдельных PulseSync-аддонов. Включать его рекомендуется только при использовании аддонов, которым действительно требуется `window.pulsesyncApi`.

### FckCensor и маркировка нежелательного контента

В проекте сохранён аддон `FckCensor-jsdelivr`. Он может обрабатывать названия и текст треков, в том числе треки, автоматически попавшие в раздел «Моя волна». Для работы сетевых запросов в Electron в проекте предусмотрены необходимые разрешения Content Security Policy.

### Асинхронная загрузка аддонов

Аддоны из папки `addons/` загружаются через собственный загрузчик проекта. Каждый аддон может быть включён или выключен через меню TuneRift Mod, а его состояние сохраняется между запусками.

Поддерживаются:

- JavaScript-скрипты;
- CSS-стили;
- стандартные метаданные PulseSync;
- включение по умолчанию или ручное включение;
- отдельные настройки аддона;
- совместимость с MAIN world страницы.

## Установка для разработки

### Требования

Для запуска исходного кода нужны Node.js и npm. Поддерживаемая платформа зависит от установленной версии Electron и доступных инструментов сборки.

### Установка зависимостей

Клонируй репозиторий и установи зависимости:

```bash
git clone https://github.com/griaa125/TuneRift-Mod.git
cd TuneRift-Mod
npm install
```

### Запуск

Запусти приложение в режиме разработки:

```bash
npm start
```

При первом запуске может потребоваться авторизация в Яндекс Музыке. Сессия хранится локально в профиле Electron, поэтому после повторного запуска вход обычно сохраняется.

## Аддоны

### Формат собственного аддона

Создай папку внутри `addons/`, добавь файл `addon.json` и JavaScript-файл:

```text
addons/
└── my-addon/
    ├── addon.json
    ├── index.js
    └── style.css
```

Минимальный `addon.json`:

```json
{
  "id": "my-addon",
  "name": "Мой аддон",
  "description": "Описание функции аддона",
  "enabledByDefault": false,
  "script": "index.js",
  "style": "style.css"
}
```

Поле `style` можно не указывать, если аддону не нужен CSS. Скрипт запускается в контексте страницы Яндекс Музыки, поэтому при работе с DOM следует учитывать, что классы и структура сайта могут изменяться после обновлений Яндекса.

### Включение аддона

После добавления аддона перезапусти приложение и открой пункт **TuneRift Mod** в меню аккаунта. Включение и отключение выполняется переключателем, а состояние сохраняется автоматически.

## Chrome-расширения Electron

Расширения из папки `extensions/` загружаются как unpacked extensions в Electron-процесс. Проект рассчитан на расширения с content scripts, которые работают на страницах `https://music.yandex.ru/*`.

Поддержка Manifest V2 зависит от версии Electron. Manifest V3 поддерживается частично: content scripts обычно работают, однако фоновые service worker и отдельные API Chrome могут иметь ограничения Electron.

Каждое расширение должно содержать собственный `manifest.json`. Пример:

```json
{
  "manifest_version": 3,
  "name": "My TuneRift Extension",
  "version": "1.0.0",
  "content_scripts": [
    {
      "matches": ["https://music.yandex.ru/*"],
      "js": ["inject.js"],
      "run_at": "document_start",
      "world": "MAIN",
      "all_frames": false
    }
  ]
}
```

## Сборка приложения

Установщики создаются с помощью `electron-builder`:

```bash
npm run build
```

Результат сборки появляется в папке `dist/`. Для публикации на GitHub Releases используются готовые установочные файлы, а не папка `dist` целиком.

В проекте настроены брендирование приложения, собственные иконки и название продукта **«Яндекс Музыка»**. Поддерживаются подготовленные сборки для macOS Universal и Linux x64 AppImage.

Примерные команды для платформенной сборки:

```bash
# macOS Universal
npm run build -- --mac --universal

# Linux x64 AppImage
npm run build -- --linux AppImage
```

Конкретный набор доступных целей определяется платформой, установленной версией Electron Builder и конфигурацией `package.json`.

## Известные ограничения

TuneRift Mod зависит от текущей структуры и API веб-версии Яндекс Музыки. После крупных обновлений сайта отдельные CSS-селекторы, элементы меню или аддоны могут потребовать обновления.

Некоторые Chrome API, особенно связанные с Manifest V3, работают в Electron не полностью. Возможности PulseSync-совместимых аддонов также зависят от того, какие API они используют.

Состояние входа, настройки и профиль Electron хранятся локально на компьютере пользователя. При удалении профиля приложения потребуется повторная авторизация.
