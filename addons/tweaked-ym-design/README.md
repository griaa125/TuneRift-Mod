# Tweaked Yandex Music Design

Аддон PulseSync для улучшенного и изменённого дизайна Яндекс Музыки: прогрессивное размытие строк синхронизированного текста, как в Apple Music, обложка трека вместо скучного фона в полноэкранном режиме и небольшие доработки на главном экране моей волны

## Настройки

В PulseSync → Settings аддона:

- **Enable blur effect** — вкл/выкл
- **Max blur** — потолок размытия (px)
- **Blur per line** — прирост blur на каждую строку
- **Min opacity** / **Opacity fade per line** — затухание дальних строк
- **Transition** — длительность анимации (ms)
